# 2026 천안시 청년정책 — 웹 프레젠테이션

원본 PPTX의 10개 슬라이드를 시각적으로 동일하게 유지한 GitHub Pages용 정적 웹 프레젠테이션입니다.

## 배포 방법

1. ZIP을 압축 해제합니다.
2. `index.html`, `style.css`, `app.js`, `slides.json`, `assets/` 전체를 GitHub 저장소의 **루트**에 업로드합니다.
3. 저장소 Settings → Pages → Build and deployment → Deploy from a branch에서 `main` / `(root)`를 선택하고 저장합니다.
4. 발급된 `https://사용자명.github.io/저장소명/` 주소에서 실행합니다.

`index.html`을 바로 열어도 기본 기능은 작동하며, 웹호스팅에 별도 서버·빌드·DB가 필요하지 않습니다.

## 이용법

- 상단 메뉴, 좌우 버튼, 키보드 방향키, 모바일 좌우 스와이프 및 슬라이드 위 휠 스크롤로 이동
- `O`: 슬라이드 전체 보기 · `I`: 발표 노트 · `F`: 전체 화면 · `Esc`: 창 닫기
- 마지막 장의 **영상 재생** 버튼: 원본 PPTX에서 추출한 MP4 재생
- URL `#slide-5` 등으로 특정 장에 직접 연결

## 구조

- `index.html`: 시맨틱 HTML, 웹 화면
- `style.css`: 반응형 디자인과 전환 애니메이션
- `app.js`: 탐색, 키보드/터치, 모달, 영상 제어
- `slides.json`: 슬라이드별 텍스트 데이터(향후 확장용)
- `assets/slide-01.webp` ~ `slide-10.webp`: 원본 슬라이드 고품질 렌더링
- `assets/youth-video.mp4`: 원본 PPTX 포함 동영상

원본의 모든 화면 텍스트, 그래픽, 인포그래픽, 이미지는 슬라이드 이미지로 보존됩니다. 텍스트와 차트의 각 요소를 별도 HTML 개체로 분리한 형태는 아니며, 접근성과 검색 가능성을 위해 제목·요약·발표 노트를 별도로 제공합니다. 이미지에 포함된 수치와 정책 정보는 원본을 따르며 최신 사업 공고를 별도로 검증한 것은 아닙니다.
